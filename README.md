# Trilha EsPCEx 2026: páginas de estudo

Páginas HTML de estudo da Trilha de Estudos EsPCEx 2026 (Estratégia Militares).
Cada tarefa de estudo tem a sua página, com resumo, mapa mental clicável, esquemas, todas as questões do ciclo
(interativas, com comentário e rendimento) e flashcards com repetição espaçada.

**Site:** https://alexsborne.github.io/espcex/

Comece pelo [`index.html`](index.html), que lista os ciclos. Cada ciclo tem a sua página (`ciclo_3.html` etc.)
com todas as tarefas propostas e o link para as que já têm página.

| Ciclo | Página |
|---|---|
| 3 | [`ciclo_3.html`](ciclo_3.html) |

As respostas e as marcações de texto ficam salvas no próprio navegador.
